# Extra stages

Under **Extras** on the main window. UNI2 builds two stages it never puts on any list, and the code
that loads a stage never looks at the flags that hide it, so they play like any other:

- **煌朧の祭壇**, the altar - a finished stage, thumbnail, localised name and all.
- **The debug stage** - no background at all, just the grid.

Nothing on disk is touched and unticking puts the flags back exactly as they were.

Hilda's UNI1 stage is not one of these. UNI2's stages are 3D models and nothing of UNI1's is in this
game's data, so it would have to be built rather than unlocked. The stage the game already offers as
number 23 is French-Bread's own **new** Hilda stage.
