# Frame meter

Press **F3**.

A band per state, the frame count printed inside each finished band, the exchange totalled on its
own line, and a status row naming every invincibility active on that frame. Frame advantage comes
from the game's own advantage field, not from reading the animation.

It starts near the bottom of the screen and drags with the mouse. It is drawn straight onto the back
buffer and has none of the overlay's hit testing, so a click that lands on it moves it whatever else
you were doing.
