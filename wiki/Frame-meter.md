# Frame meter

Press **F3**.

It shows a band for each state, with the frame count inside each finished band. The total for the
exchange is on its own line, and a status row lists every invincibility active on that frame. Frame
advantage comes from the game's own advantage value, not from reading the animation.

It starts near the bottom of the screen and you can drag it with the mouse. It is drawn straight on
the screen, outside the overlay, so a click on it always moves it, whatever else you were doing.
