**UNDER NIGHT IN-BIRTH II Sys:Celes** (Steam、`uni2.exe`) 用のトレーニング・利便性向上 MOD です。

`dinput8.dll` として読み込まれ、ゲーム画面の上に Dear ImGui のオーバーレイを表示します。

## オンラインについて

**この MOD には、オンラインで有利になる機能はありません。**

対戦の内容を変えうるトレーニング機能はすべてオフライン専用です。フレーム送り、一時停止、キャラクターの手動操作、ダミースクリプトがこれにあたります。直近 3 秒以内に対戦相手へパケットを送っていれば、これらは動きません。本作は GGPO ロールバックを使っているので、対戦中に状態を変えると同期ずれが起きます。

オンラインで動くのは、見た目だけの機能です。カスタムパレットは Steam 経由で別に送られるので、対戦に影響しません。パフォーマンス設定は、映像をモニターへ出す方法を変えるだけです。

**パッチセレクターは例外で、オフライン専用です。** パッチは対戦の内容そのものを変えます。技データとシステム定数は起動時に一度だけ読まれ、セッション中ずっと残ります。パッチで起動したら、メニューを移動してもオンラインに出てもそのままです。同じパッチを選んだ相手としか対戦できません。**ランクマッチや、同じパッチを選んでいない相手とは使わないでください。同期ずれが起きます。** 対戦する前に、インストール版で起動し直してください。

実際の対戦で有利になるものを見つけたら、それは不具合です。報告してください。

## インストール

リリースの zip を `uni2.exe` と同じフォルダーに展開します。

```
<Steam>\steamapps\common\UNDER NIGHT IN-BIRTH II Sys Celes\
```

中身は 2 ファイルです。`dinput8.dll` が MOD 本体です。`UNI2IMUpdater.exe` は新しいバージョンを入れるためのもので、なくても MOD は動きます。

ゲーム中に **F1** でオーバーレイを開きます。アンインストールは 2 ファイルを削除するだけです。

`UNI2_IM.ini` は初回起動時に `UNI2-IM` フォルダーへ既定値で作られます。その後は起動のたびに、足りないキーやセクションだけが既定値で追加されます。編集した値はそのままです。削除すれば既定値に戻ります。各キーの説明は [The ini file](The-ini-file) にあります。

## Linux / Steam Deck (Proton)

`dinput8.dll` を Windows と同じ場所に置き、次の手順を 1 つ追加します。

1. Steam ライブラリでゲームを右クリック → **プロパティ**。
2. **一般** の **起動オプション** に、この行をそのまま貼ります。

```
WINEDLLOVERRIDES="dinput8=n,b" %command%
```

3. ゲームを起動して **F1**。

これで完了です。ファイル名の変更や追加のコピーは要りません。

**なぜ必要か。** この行が無いと、Wine は MOD の DLL を読みません。`n,b` は「まずネイティブ、次に内蔵」という意味です。MOD の DLL が読まれ、コントローラー入力は Wine 自身の `dinput8` がそのまま処理します。

Proton 9 以降では自動でこうなるので、この行があっても問題ありません。古い Proton では必要です。

Linux では **互換セーフモード** が自動で有効になります。フルスクリーンのリフレッシュレート変更、電源スロットリング解除、`Sleep` の差し替えは行いません。`[Compat] WineSafeMode = 0` で無効にできます。

何も起きないときは、`uni2.exe` の隣に `UNI2-IM` フォルダーがあるか確認してください。無ければ DLL が読まれていません。上の手順を見直してください。

## RivaTuner / MSI Afterburner などのオーバーレイ

この MOD は他のツールのフックを上書きしません。RTSS や Steam オーバーレイと一緒に使えて、読み込み順も関係ありません。

それでも問題が出るときは、`[Debug] Logging = 1` を設定して 1 回起動してください。`UNI2-IM/Logs` のログに、どのフックで何が起きたかが出ます。RTSS 側では次の 2 つを設定してください。

- **Settings → General → Injection properties → "Use Microsoft Detours API hooking"**
- **ゲームの RTSS プロファイル → Application detection level → None**

## 機能

### オーバーレイ

**F1** で開きます。Training、Custom、Config の 3 セクションが 1 つのウィンドウにあります。ヒットボックス表示、フレームメーターの凡例、Player Control、Performance、Music、Stages は別ウィンドウです。

文字を入力している間とキー割り当てを設定している間は、キーボード入力がゲームに届きません。

### ヒットボックス表示

**F2**。キャラクターと飛び道具のボックスを、ゲームと同じ色で表示します。装飾用のボックスは表示しません。

投げ、D シールド、近距離ガードのボックスはありません。ゲームに存在しないからです。投げの判定は、投げ属性を持つフレームの通常の攻撃ボックスです。

### フレームメーター

**F3**。状態ごとの帯、各帯のフレーム数、やり取りの合計、そのフレームで有効な無敵を表示します。フレーム有利はゲーム自身の値を使っています。

画面の下の方に表示され、マウスでドラッグできます。オーバーレイのクリック判定を持たないので、上をクリックするとメーターが動きます。

### 一時停止とフレーム送り

**F5** で停止、**F6** で 1 フレーム送り、長押しで連続して送ります。

停止方法は 2 つです。*Tick stop* はゲーム全体を止めます (既定)。*Hitstun Stop* はヒットストップを使って止めます。メニューは動きますが、エフェクトは正しく表示されません。

オートポーズは、攻撃、アーマー技、コンボの指定ヒット数で停止します。カウントダウンのあとに再開できます。

### Player Control

専用ウィンドウです。両サイドの入力を、テンキー表記と 4 つのボタン表示でリアルタイムに見られます。自分のパッドやキーボードでどちらのキャラクターも操作できます。ダミーに方向やボタンを押し続けさせたり、数フレームだけ入力させたり、サイドごとにスクリプトを動かしたりできます。

入力遅延も測れます。ボタンを押してから、キャラクターに入力が届くまでの時間です。キーボードとパッドは毎秒約 1000 回読み取っています。

### キーボードのサイド

*Config → Keyboard* で、キーボードを **1P** と **2P** のどちらにするか選びます。キー設定はそのままで、独立したプレイヤーになります。1 台の PC で 2 人が遊ぶローカル対戦向けです。

ゲームはキーボードと 1 番目のコントローラーを同じプレイヤーとして扱うので、ローカル対戦では同じキャラクターを動かしてしまいます。ここでサイドを選ぶと、**コントローラー** がもう一方のサイドへ移ります。キーボードとそのキー設定は変わりません。

オンラインでは効果がありません。

### パレット

どちらのキャラクターの色も、その場で変えられます。色は画面の左右ではなくキャラクターに属するので、左右が入れ替わってもついてきます。最後に使った色は記憶され、次回自動で使われます。

パレットはゲームと同じ `.pal` 形式です。`UNI2-IM\Palettes\<キャラクター>` に、名前・作者・説明と一緒に保存されます。エフェクトの色もパレットに含まれます。

オンラインでは、自分のパレットが Steam 経由で相手に送られます。相手のパレットをどう表示するかは **See the other player's colours** で選びます。MOD を入れていない相手には見えません。

**Palette Nativa** は別の機能です。ゲーム自身のカラーカスタマイズをオーバーレイから操作します。自由な色は作れませんが、ゲームに保存され、**すべての** 対戦相手に見えます。

### ボイスとサウンド

キャラクターのボイスや効果音を差し替えます。変わるのはそのキャラクターだけです。

**Replace** タブでキャラクターを選び、**Load voices and sounds** を押します。戦闘ボイス、ストーリー、勝利セリフ、アナウンス、メニューと選択、共通の効果音が表示されます。

**Get this voice from UNI...** を使うと、手元にある旧作 (`UNIclr.exe`、`UNIst.exe`、`UNIEL.exe` があるフォルダー) からボイスを取り込めます。セリフの文面で照合するので、一致するのはおよそ 3 分の 2 です。剣、宇津貴、輝夜、久遠、オウガ、泉は UNI にいません。

差し替えたファイルは `UNI2-IM\Sounds` の pack に入ります。**Ogg Vorbis を使ってください。** WAV と MP3 は一度だけ変換してキャッシュします。音声ファイルは MOD に含まれていません。

### Player Card

対戦相手に表示されるカードを編集します。プレートの 4 レイヤーとタイトルを変えられます。タイトルは自由に入力でき、そのまま相手に表示されます。

### BGM セレクター

**Music** から開く専用ウィンドウです。どの画面にも好きな曲を割り当てられます。

**Get OST from French-Bread games** で、手元にある作品のサウンドトラックを読み込みます。`UNIclr.exe`、`UNIst.exe`、`MBTL.exe`、`MBAA.exe` のどれかがあるフォルダーを選んでください。曲名とループ位置も一緒に入ります。ダウンロードはしません。音声ファイルは MOD に含まれていません。

**Browse** は再生できる全曲の一覧です。**Randomizer** は、曲が必要になるたびに一覧からランダムに選びます。曲ごとに **Volume** を設定でき、`UNI2-IM/bgm.ini` に保存されます。100% が元の音量で、それより大きくはできません。

**Rules** で曲を手動で割り当てます。**Import music** で MP3・OGG・WAV を取り込めます。

### ステージ

メインウィンドウの **Stages** です。2 種類のステージを使えます。UNI2 がセレクターに出していないステージと、手元にある他の French-Bread 作品のステージです。

ステージ一覧は起動時に一度だけ読まれます。ここで変えた内容は、ゲームを再起動すると反映されます。

隠れているステージは **煌朧の祭壇** と **デバッグステージ** (背景なし、グリッドのみ) の 2 つです。

他の作品から持ってくるには、**Get stages from French-Bread games** を押し、`MBTL.exe`、`UNIclr.exe`、`UNIst.exe` のどれかがあるフォルダーを選びます。MBTL と UNI は UNI2 と同じ形式なので、変換は要りません。手元のファイルを読んで、新しいステージとして追加します。ゲームの元のファイルは置き換えません。名前は英語で、サムネイルは元の作品のものを使います。

MBAACC のステージは使えません。背景が 2D で、UNI2 とは形式が違います。音楽は取り込めます。

### Performance

Config から開く専用ウィンドウです。ゲームのフレームペーシング (フレームの間隔) の問題と、バックグラウンドに回したあとのタイマー精度の低下に対処します。

設定は 3 つ、プリセットは 2 つです。ウィンドウには **実際に** 使われている値が表示されます。**Metrics** タブで計測できます。

### POTATO MODE

Performance ウィンドウのタブです。60 fps が出ない PC 向けです。

**どの段階でもステージは表示され、画面のサイズは変わりません。**

| 段階 | 描画解像度 | その他 |
|---|---|---|
| Off | ゲームの Display 設定 | なし |
| Balanced | 960x540 | バックバッファーのマルチサンプリング off |
| Potato | **480p / 360p / 240p / 144p** | Character Visual Improvements も off |

**サイズはウィンドウに対する割合ではなく、固定の値です。** 640x360 は、ウィンドウが 720p でも 1440p でも 640x360 で描かれ、画面に合わせて引き伸ばされます。位置はずれません。画像がぼやけるだけです。

排他フルスクリーンでは、実際に使える表示モードに合わせてサイズが切り上げられます。設定は、次にゲームが表示を作り直したときに反映されます。**対戦の内容には一切影響しません。**

### Improvements

同じウィンドウにある、逆向きの設定です。ウィンドウより **大きく** 描いてから縮めます。

キャラクターとステージは 1280x720 固定で描かれるので、スプライトはきれいになりません。きれいになるのは HUD、メニュー、輪郭、MOD のオーバーレイです。

同じタブの **Sharpening** の方が効果があります。40-60% がおすすめです。ウィンドウとボーダーレスでのみ使えます。

### Memory debug

既定では無効です。`[Debug] MemoryDebug = 1` を設定して **Ctrl+F1** を押します。
