# Keyboard side

*Config → Keyboard.*

Choose whether the keyboard plays **1P** or **2P**. The keyboard becomes its own player, with the
keys you already set up. It is made for local play at a tournament: two players on one machine, one
of them on a keyboard.

The game gives the keyboard and the first controller the same player number, so in local versus they
control the same character. When you pick a side here, the **controller** moves to the other side.
The keyboard stays where it is and its keys do not change.

It never changes your key settings, and it never moves the keyboard between the game's two keyboard
players. Both were tried and both broke something. If you set up a second keyboard player in the
game's own options, those keys work on the controller's side. Set *Keyboard Player Number* to 1 there
to turn them off.

*Hold the side during a match* keeps setting both controller slots while a local match runs, so you
always get the side you picked. Turn it off to let the game decide.

None of this runs online.
