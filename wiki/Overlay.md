# Overlay

Press **F1**.

One window with three sections: Training, Custom and Config. The hitbox viewer, the frame meter
legend, Player Control, Performance, Music, Stages and the others open in their own windows.

While you type in a text field, the keyboard goes to the overlay and the game gets nothing. The same
happens while you set a keybind. If a key is still held when you leave the field, the game ignores it
until you release it, so it never comes out as a move.
